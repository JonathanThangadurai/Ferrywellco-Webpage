# FerryWellCo website mockup

This repository contains a static review version of the FerryWellCo website.

Open `index.html` locally or publish the repository root with GitHub Pages. The site uses plain HTML, CSS and JavaScript, so it has no build step.

The example views are illustrative and do not use live forecasts.

The site uses a locally hosted Instrument Sans variable font. Its SIL Open Font License is in `assets/fonts/INSTRUMENT-SANS-OFL.txt`.

The photographs in `assets/urban-riverside-concept.jpg`, `assets/run-planning-concept.jpg` and `assets/shaded-city-walk-concept.jpg` were generated for visual exploration. They depict illustrative scenes, not real customers, locations or product use. The other photographs were supplied for this project.
